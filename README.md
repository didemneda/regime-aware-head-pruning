# Regime-Aware Attention Head Pruning

This project investigates regime-conditional attention head selection for time series Transformers.

## Initial Scope

- Model: PatchTST
- Dataset: ETTh1
- Prediction length: 96
- Regimes:
  - Trend-dominant
  - Seasonality-dominant
  - Noise-dominant
